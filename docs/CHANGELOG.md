# 0.1.0 a — Alpha

First release snapshot, corresponding to firmware `V2.43-PEQ08`.

- Retains stock ten-band EQ and its controls; swipe left to the native PEQ page.
- Independent switches, with PEQ followed by stock EQ when both operate.
- Local PCM PEQ up to 192 kHz; stock EQ skipped above 48 kHz; DSD/DoP bypasses PCM processing.
- Simplified Chinese and English UI, stock OFF artwork, and the animated current-playback shortcut.
- Four visible preset rows, a fully visible Rescan button, and OFF elements aligned with stock positions.

On 2026-10-10, the device owner confirmed the package usable on one XM5. This is user feedback, not an instrumental or long-term validation result. The final layout changes did not receive an extra functional suite or independent package verification. The startup recovery hook has not completed a hardware recovery drill.

The standalone publication source tree reproduced all four overlays and the complete delivered image byte for byte.
